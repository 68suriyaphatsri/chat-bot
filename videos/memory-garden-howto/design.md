## 1. ปรัชญาและหลักการออกแบบ

Memory Garden ถูกออกแบบบนแนวคิด **"Nature-Therapy Cognitive Gamification"** (การเปลี่ยนแบบทดสอบสมองทางการแพทย์ให้กลายเป็นการเดินเล่นในสวนธรรมชาติที่ผ่อนคลาย) โดยยึดหลัก 4 ประการ:

```
                  ┌──────────────────────────────────────────────┐
                  │          MEMORY GARDEN CORE DESIGN           │
                  └──────────────────────┬───────────────────────┘
                                         │
     ┌───────────────────┬───────────────┴───────────────┬───────────────────┐
     ▼                   ▼                               ▼                   ▼
【 1. Empathy & Calm 】 【 2. Senior-First a11y 】    【 3. Low Anxiety 】  【 4. Medical Rigor 】
  ลดความวิตกกังวล       ปุ่มใหญ่ ตัวหนังสือคมชัด       ไม่มีการจับเวลากดดัน     เกณฑ์ MoCA 30 คะแนน
  บรรยากาศสวนบำบัด       มีเสียงอ่านประกอบทุกจุด       ทำตามจังหวะตนเอง        ประเมิน 5 มิติแม่นยำ
```

1. **Empathy & Healing Aesthetic (การออกแบบที่โอบรับความรู้สึก):** ละทิ้งความรู้สึกแบบ "การสอบในโรงพยาบาล" มาเป็น "การเดินทางในสวนธรรมชาติ" ใช้โทนสีเขียวใบไม้ Earth tone เพื่อลดความเครียด (Cortisol)
2. **Senior-First Accessibility (ความสะดวกสูงสุดสำหรับผู้สูงอายุ):**
   - รองรับทั้งการพิมพ์, การแตะสัมผัส (Chips), การวาดนิ้ว (Canvas) และการใช้เสียงพูด (Web Speech API)
   - มีปุ่ม 🔊 ฟังเสียงโจทย์ในทุกข้อ
   - พื้นที่สัมผัส (Touch Targets) ขนาดใหญ่อย่างน้อย $48 \times 48\text{px}$ ขึ้นไป
3. **Low-Cognitive Friction (ไม่สร้างภาระทางความคิดที่ไม่จำเป็น):** การนำเสนอคำสั่งทีละขั้นตอน (Step-by-Step Focus) ไม่แสดงข้อมูลรกหน้าจอ
4. **Clinical Precision with Gamified Flow:** โครงสร้างคำถามตรงตามมาตรฐาน MoCA (Montreal Cognitive Assessment) แต่ผสานการเล่าเรื่อง (Narrative Walkthrough)

## 3. ระบบตัวพิมพ์และการเข้าถึงของผู้สูงอายุ

### ฟอนต์และการจัดลำดับชั้น

ระบบใช้ Google Fonts ภาษาไทย 3 แบบที่ผ่านการทดสอบความชัดเจนในการอ่าน (Legibility Test):
* **`Prompt`**: ใช้สำหรับ Heading, Title และตัวเลขคะแนนขนาดใหญ่
* **`Anuphan`**: ใช้สำหรับ UI Controls, ปุ่มกด, ฟอร์ม และข้อความคำสั่ง
* **`Sarabun`**: ใช้สำหรับบทความความรู้และย่อหน้ายาว

```

├───────────────────┼─────────────┼────────────┼─────────┼───────────────┤

```

### ระบบปรับขนาดฟอนต์แบบเรียลไทม์

ระบบรองรับ CSS Variable `--font-scale` ปรับได้ 3 ระดับผ่านปุ่มควบคุมบนหน้าจอ:
* **ขนาดมาตรฐาน (100%):** `--font-scale: 1.0` (Base 17px)
* **ขนาดใหญ่ (115%):** `--font-scale: 1.15` (Base 19.5px)
* **ขนาดใหญ่พิเศษ (130%):** `--font-scale: 1.30` (Base 22.1px)

## 5. ระบบคอมโพเนนต์ส่วนต่อประสาน

### 5.1 การ์ดและกล่องข้อความ
* **โครงสร้าง:** สีขาวทึบแสงสูง `rgba(255, 255, 255, 0.96)`, ขอบมน `24px`, ขอบเส้นประเน้นด่าน `2px dashed #82954b`
* **ความกว้างสูงสุด:** `max-width: 460px - 500px` บนจอมือถือ จัดกึ่งกลางจออย่างสมดุล

### 5.2 ปุ่มกดและการตอบสนอง
* **Primary Action Button:** Gradient สีเขียวธรรมชาติ `#82954b` ถึง `#4a6b22`, รูปร่าง Pill-shaped (`border-radius: 50px`), เงาฟุ้ง `box-shadow: 0 4px 15px rgba(130,149,75,0.35)`
* **Hover / Active State:** ขยายตัว $1.02\text{x}$ เล็กน้อย และยุบตัว $0.98\text{x}$ เมื่อสัมผัส พร้อมปิดการไฮไลต์สีฟ้าของระบบมือถือด้วย `-webkit-tap-highlight-color: transparent`

### 5.3 ระบบเสียงอ่านประกอบ (Text-to-Speech Audio Trigger)
* **สัญลักษณ์:** ปุ่มกลมสีเขียว 🔊 ขนาด $32 \times 32\text{px}$ วางข้างหัวข้อคำสั่งทุกด่าน
* **การทำงาน:** เรียกใช้ Web Speech Synthesis (`SpeechSynthesisUtterance` ภาษาไทย `th-TH`) เพื่ออ่านคำสั่งและโจทย์

### 5.4 กระดานวาดเขียนสัมผัส (Interactive Drawing Canvas)
* **Canvas Dimension:** $320 \times 320\text{px}$ กรอบโค้งมน $24\text{px}$
* **Touch Action:** กำหนด `touch-action: none` บน Canvas เพื่อป้องกันการเลื่อนหน้าจอขณะวาด
* **Stroke Styling:** เส้นหมึกสีเขียวเข้ม `#2e4414`, ความหนาเส้น $4\text{px}$ ปลายมน (`round cap`)

### 5.5 แผงรับเสียงพูดและถอดความ (Speech Recognition Panel)
* **Microphone Button:** ปุ่มไมค์ 🎙️ ขนาดใหญ่ มีกรอบเปลี่ยนสถานะ:
  - **โหมดรอสัมผัส:** พื้นหลัง `#e8ede0`, ขอบเขียว `#82954b`
  - **โหมดกำลังฟัง (Listening):** พื้นหลัง `#e8f5e9`, ขอบเขียวนีออนกระพริบ พร้อมป้าย *"🔴 กำลังฟังเสียงพูด... พูดได้เลยครับ"*
* **Real-Time Text Feed:** แสดงคำที่ระบบได้ยินทันที พร้อมปุ่ม ✕ เพื่อล้างข้อความหากต้องการพูดใหม่

### 5.6 วิดเจ็ตจับเวลาลอยตัว (Floating Cognitive Timer Widget)
* **สไตล์:** แคปซูลขอบเขียวมนลอยมุมขวาบน (`position: fixed; top: 18px; right: 18px`)
* **องค์ประกอบ:** ไอคอน ⏱️ กระพริบช้าๆ + ตัวเลขดิจิทัล `00:00` ฟอนต์ Monospace

### 5.7 หน้าสรุปผลคะแนนและบทวิเคราะห์ AI
* **Score Ring / Metric:** แสดงคะแนนตัวเลขขนาดใหญ่ `XX / 30` พร้อมป้ายระบุโบนัสวุฒิการศึกษา `🎓 +1 Bonus`
* **5-Domain Breakdown Card:** การ์ดแจกแจงคะแนน 5 แถวพร้อมแถบ Progress Bar สีเขียว
* **AI Cognitive Insight Card:** กล่องพื้นหลัง Gradient สีเขียวอ่อนมินต์ `#f0f7e6` สรุปจุดแข็งของสมอง และแนวทางการปฏิบัติตัว 3 ข้อ

## 6. ระบบการเคลื่อนไหวและแอนิเมชัน

```css
/* Animation Keyframes Definition */

/* 1. Pulse Alert สำหรับไอคอนและปุ่มไมค์ */
@keyframes pulse-soft {
    0% { transform: scale(1); opacity: 1; }
    50% { transform: scale(1.06); opacity: 0.85; }
    100% { transform: scale(1); opacity: 1; }
}

/* 2. Spring Pop การ์ดและชิปตัวเลือก */
@keyframes elastic-pop {
    0% { transform: scale(0.6); opacity: 0; }
    70% { transform: scale(1.08); opacity: 1; }
    100% { transform: scale(1); }
}

/* 3. White Fade Transition ระหว่างด่าน */
@keyframes pageFadeIn {
    from { opacity: 0; transform: translateY(12px); }
    to { opacity: 1; transform: translateY(0); }
}
```

* **Timing Curve:** ใช้ `cubic-bezier(0.25, 0.1, 0.25, 1)` สำหรับการเลื่อนสลับหน้าจอที่นุ่มนวล
* **Reduced Motion Support:** รองรับ `@media (prefers-reduced-motion: reduce)` โดยปิดแอนิเมชันที่เคลื่อนไหวรุนแรงสำหรับผู้ที่มีปัญหาการมองเห็นหรือเวียนศีรษะ

## 7. มาตรฐานการเข้าถึงและการออกแบบเพื่อทุกคน (Accessibility - a11y)

| หัวข้อตรวจสอบ (Checklist) | รายละเอียดการปฏิบัติตามมาตรฐาน | สถานะ |
| :--- | :--- | :---: |
| **Color Contrast (WCAG AAA)** | อัตราส่วนความต่างของสีตัวหนังสือกับพื้นหลังเกิน $7:1$ ในจุดสำคัญ และเกิน $4.5:1$ ในจุดทั่วไป | ✅ ผ่าน |
